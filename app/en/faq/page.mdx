# FAQ

## Installation & Setup

### How do I install DeepShare?

See the [Installation Guide](/en/installation).

### I can't see the buttons after installation. What should I do?

**Causes and solutions:**

1. **Page not refreshed**: After installation, refresh any open AI chat pages (press F5)
2. **Extension not enabled**: Check the browser extensions management page and ensure DeepShare is enabled
3. **Platform not supported**: Confirm the AI platform you are visiting is in the [supported list](/en/platforms)
4. **Browser compatibility**: Make sure you are using the latest version of Edge, Chrome, or Firefox

### How do I configure the API Key?

**Steps:**

1. [Purchase an API Key](/en/pricing)
2. Click the DeepShare icon in the browser toolbar (blue bird)
3. Paste your API Key

## Feature Usage

### Which platforms support one-click Word export?

Currently supported platforms for one-click export:

- ✅ DeepSeek
- ✅ ChatGPT
- ✅ Gemini

Other platforms support the manual paste method. View the [full supported list](/en/platforms).

### How do I export to Word from Doubao and other platforms?

For platforms that do not support one-click export, use the manual paste method:

1. Click the copy button (❐) at the end of the AI response
2. Open the DeepShare extension popup
3. Paste the copied content
4. Click "Convert to Document"
5. Download the generated Word document

You can also use the [online converter](https://ds.rick216.cn/converter-en.html).

See the detailed tutorial: [Doubao Export to Word](/en/usage/doubao-to-word)

### How do I copy formulas?

See [Tutorials - Copy Formulas](/en/usage/copy-formula).

## Technical Issues

### Word export failed. What should I do?

**Common causes and solutions:**

1. **API Key error**
   - Check that the API Key is correct
   - Make sure there are no extra spaces

2. **Insufficient quota**
   - Check remaining conversions
   - Renew in time

3. **Network issue**
   - Check your network connection
   - Try enabling or disabling a VPN
   - IP may be blocked — try switching VPN nodes

4. **Content format issue**
   - Simplify the conversation content
   - Remove special characters
   - Convert in sections

### Formula copying isn't working.

**Solutions:**

1. **Refresh the page**: Press F5 to refresh the AI chat page
2. **Check the extension**: Confirm DeepShare is enabled
3. **Platform support**: Confirm the platform supports formula copying
4. **Reinstall**: Uninstall and reinstall the extension

### Screenshot generation failed.

**Possible causes:**

1. **Conversation too long**: Try taking screenshots in sections
2. **Insufficient memory**: Close other tabs
3. **Platform limitation**: Only DeepSeek supports screenshots

### Extension icon not showing.

**Solutions:**

1. Check if the extension is pinned to the toolbar
2. Check if the extension is installed
3. Enable the extension in the extensions management page
4. Restart the browser
5. Reinstall the extension

### The exported Word format is wrong.

**Optimization methods:**

1. **Formula issues**: Ensure the original formula format is correct
2. **Table issues**: Complex tables may require manual adjustment
3. **Code issues**: Check the code block format
4. **Feedback**: [Contact us](/en/contact) to report the issue

### Firefox shows a security warning.

This is normal — temporarily installed extensions show this warning.

**Solution:**
- Click "Continue"
- Or install from the official Firefox Add-ons Store

## Privacy & Security

### Does DeepShare collect my data?

**No!** DeepShare adheres to a zero data collection principle:

- ❌ No personal information collected
- ❌ No browsing behavior tracked
- ❌ No analytics tools used
- ✅ All processing done locally
- ✅ Word conversion data deleted immediately

See the [Privacy Policy](/en/privacy) for details.

### Is the API Key secure?

**Security measures:**

- 🔐 Encrypted storage in the browser locally
- 🔐 HTTPS encrypted transmission
- 🔐 Not persistently stored on servers

**Security recommendations:**
- Do not share your API Key with others
- Check usage regularly
- Contact us immediately if you notice anything unusual
