# Select Word Template

<Callout>

Please ensure the DeepShare extension is installed in your browser. If not, see the [Installation Guide](/en/installation).

This feature requires purchasing an API Key. [View pricing](/en/pricing).

</Callout>

Select different Word templates to control the style of exported Word documents.

<Steps>

### Click the DeepShare extension in the toolbar

If you can't find the extension, first [pin DeepShare to the toolbar](/en/installation#pin-deepshare-to-toolbar).

![Click DeepShare](/images/deepshare/click-deepshare.png)

### Select a Word template

Select a Word template in "Manual Document Conversion". The selection applies globally.

![Select Word Template](/images/deepshare/select-word-template.png)

</Steps>
