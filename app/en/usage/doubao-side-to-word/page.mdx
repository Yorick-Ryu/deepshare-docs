# Doubao "Writing Assistant" Export to Word

<Callout>

Please ensure the DeepShare extension is installed in your browser. If not, see the [Installation Guide](/en/installation).

This feature requires purchasing an API Key. [View pricing](/en/pricing).

</Callout>

<Steps>

### Download Markdown

Hover over the completed article, click download, and select "Markdown" format.

![Download](/images/doubao/download-md.png)

### Open the downloaded file

On Windows, open with Notepad.

On Mac, open with TextEdit, or rename the file extension to `.txt` and open it.

![Open Markdown](/images/doubao/open-md.png)

### Copy all content

Use `Ctrl+A` and `Ctrl+C` to copy all content.

![Open Markdown](/images/doubao/copy-md.png)

### Paste into the extension to convert

Open the extension, go to the "Manual Document Conversion" tab, paste the copied content, and click "Convert to Document".

If you can't find the extension, first [pin DeepShare to the toolbar](/en/installation#pin-deepshare-to-toolbar).

![Save Docx](/images/doubao/paste.png)

### View the converted document

The document will be automatically downloaded. Open it with Word or WPS.

![Word](/images/doubao/word.png)

</Steps>
