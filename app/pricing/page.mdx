## 如何购买与使用

### 购买步骤

1. 访问 [套餐购买页](https://ds.rick216.cn/price.html) 或 [次数购买页](https://ds.rick216.cn/purchase.html)
2. 填写您的邮箱（用于接收 API Key）
3. 完成支付后，系统会自动显示并发送 API Key 到您的邮箱

### 配置插件

1. 在浏览器工具栏点击 DeepShare 图标
2. 在设置中填入您收到的 **API Key**
3. 之后在支持的 AI 对话页面即可看到“导出 Word”按钮

## 查询与续费

### 查询配额

您可以通过以下方式查询剩余次数：
- **插件弹窗**：点击浏览器图标，直接查看当前 Key 的剩余次数及有效期。
- **在线查询**：在 [购买页面](https://ds.rick216.cn/purchase.html) 的“查询剩余次数”部分输入 Key 即可查看详细明细。

### 续费与充值

当您的配额不足或即将到期时：
- 访问 [续费/充值页面](https://ds.rick216.cn/renew.html)
- 输入现有 API Key 进行续订，对应的次数或时长会累加到您的账户。

**注意**：续费会从操作当前的到期时间起，额外延长 1 年有效期。
