# 选择Word模版

<Callout>

请确保浏览器已安装 DeepShare 插件，未安装请查看[安装指南](/installation)

本功能需要购买API-KEY，[点此查看定价](/pricing)

</Callout>

选择不同的Word模版，控制导出的Word的样式

<Steps>

### 点击工具栏中的DeepShare插件

如果没找到插件的话请先[在工具栏中固定DeepShare](/installation#在工具栏中固定deepshare)
![Click DeepShare](/images/deepshare/click-deepshare.png)

### 选择Word模版

在「手动转换文档」里面选择Word模版，选定后会在全局生效
![Select Word Template](/images/deepshare/select-word-template.png)

</Steps>
